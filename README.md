# Hitesh Industries Website

A responsive static website for Hitesh Industries, Bengaluru, featuring product pages, a project gallery, and a quotation request form.

## Preview locally

Open `index.html` in a modern web browser. Keep the `images/`, `media/`, and `solutions/` folders alongside it.

The quotation form opens a prefilled email draft. Customers must attach selected files in their email app before sending. The gallery manager mode uses browser-local storage; it is not a server-backed upload system.
